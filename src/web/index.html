      Image Output

      2592 × 1944

      Applied immediately to the live view, archived frames and frames synced to hoan.uk. The sensor still reads the full frame; RAW10 frames are binned 2×2 / 4×4 before demosaicing when the size allows, otherwise downscaled by pixel averaging. Smaller sizes cost much less CPU and also reduce noise and file size.

      Resolution

      Timelapse, keogram and startrails are always stored at 1296 × 972, so changing the resolution does not affect them.

      Star boost (night)

      Sums each star's light over an N×N window above the sky background (stars ~N² brighter, noise only ~N×), so faint stars survive the downscaled live view. Only while the sun is below −6°, only inside the sky mask; the image size, star count, cloud cover and archived frames are unchanged.

      Performance

      Raise the capture interval or lower the sizes if the computer runs hot; exposures longer than the interval are not affected. Cloud cover is sampled day and night (stars only at night); each sample is plotted under Live → Cloud Cover History.

      White Balance

      Applies to RAW10 frames (night, or exposure ≥ 0.4 s) and as a gentle correction on top of the camera ISP in MJPG mode (daytime). In use: --

      Orientation (Mirror / Flip / Rotate)
      Native sensor orientation (no transform)

      Detection

      Meteor, aircraft, satellite, flash and cloud detection, and the cloud cover analysis.

      Event detection

      Streaks and flashes are looked for at night only (sun below −8°), on a 640 px gray copy of each new frame compared with the previous one: a few ms per frame. A streak in a single frame is a meteor; a dashed one or one that continues along the same line in the next frame is an aircraft (faint and steady: a satellite). Cloud changes reuse the cloud cover samples, so they need “Star count & cloud cover” on. Set a sky mask (plate solving) to ignore roads and windows. Events are listed under Gallery & Events.

      Cloud Cover

      Only this part of the frame is analysed: exclude buildings, trees and the horizon (e.g. bottom 40% if the lower part shows rooftops). The clear-sky reference is learned automatically; reset it after moving or re-aiming the camera.

      Sky Mask

      Plate-solve sky mask (outline the open sky)

      Click on the frame to outline open sky (green) and lit buildings, trees or poles to ignore (red). The plate solver only uses stars inside the sky and outside obstructions, on top of its own automatic sky detection.

      Integrations

      ADS-B receiver

      With a local ADS-B receiver (dump1090, readsb or a Flightradar24 feeder: BaseStation port 30003), each aircraft event is matched to the flight whose position, projected with the star-solved camera pointing, lies on the streak. A “meteor” that matches a flight becomes an aircraft. The feed is only read at night while aircraft detection is on.
