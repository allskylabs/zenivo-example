# Security policy

## Supported versions

Only the latest release receives security fixes. Check your version with `python3 run_allsky.py --version`.

## Reporting a vulnerability

Please report it privately: on the repository page open **Security**, then **Report a vulnerability**
(GitHub private vulnerability reporting). Do not open a public issue for a security problem.

Include the version, what you did, what you expected and what happened. Reports are handled by volunteers,
so please allow some days for a first answer.
